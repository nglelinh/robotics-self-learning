# References and Resources

This page contains references and resources for the course. Add your own references as needed.

## Interactive 3D Board Labs (supplementary)

Free browser-based labs that complement the hands-on chapters. All run in the browser with Three.js; no hardware needed. Use them to preview a circuit before wiring it on the real board.

- *[Learn ESP32](https://learn-esp32.vercel.app/)* (Dilum Sanjaya). 20 beginner lessons on a 3D ESP32 board: LEDs, buzzer, Wi-Fi, Bluetooth, ESP-NOW, distance sensing, wheels, ultrasonic radar, pick-and-place. Vietnamese available. Matches the course default MCU (ESP32).
- *[Learn Arduino](https://learn-arduino-red.vercel.app/)* (Dilum Sanjaya). 16 beginner lessons on a 3D Arduino Uno: LED, button, potentiometer, LDR, HC-SR04, buzzer, DC motor via transistor, TMP36, servo, stepper, soil sensor + OLED, FSR, final distance + traffic-light project. [Vietnamese version](https://learn-arduino-red.vercel.app/vi/). Same API as the Arduino Mega 2560 used as the 5 V bench reference.
- *[Robotics Lab](https://robotics-lab-app.vercel.app/)*. Eight boards (Uno, Nano, Mega 2560, ESP32, NodeMCU, Pico, STM32 Blue Pill, Raspberry Pi 4) in 3D with part-by-part lessons, a "find the part" quiz, take-apart/solder-back assembly, and a comparison table (MCU, logic voltage, price). Useful for choosing a board and remembering 3.3 V vs 5 V logic. The wiring workbench was still under construction as of 2026-11-21.
- *[Things Workshop](https://www.things-workshop.com/)* (Cameron Priest). Interactive 3D mechanism explainers; most relevant: [How many joints does a robot arm need?](https://www.things-workshop.com/explore/how-many-joints-does-a-robot-arm-need/) and [Inside a robotic actuator](https://www.things-workshop.com/explore/actuator-explorer/).
